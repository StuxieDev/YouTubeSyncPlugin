Folder where YouTube items are created. This must already be inside a Jellyfin library.
Public or local Jellyfin address written into playback links, for example https://jellyfin.example.com. It must be reachable by the devices that will play these items.
How long playback links are kept before the plugin asks YouTube for fresh ones.
Used when Enhanced playback is disabled or unavailable. Compatibility first prefers simpler 720p-friendly streams, Balanced aims for a good middle ground, and Highest single-stream quality asks YouTube for the best single stream it can provide.
Only videos published within this age window are kept in Jellyfin. Set to 0 to keep everything.
For channel sources using the playlists feed, only this many of the most recent playlists are kept. Set to 0 to keep all playlists. Videos inside kept playlists are not filtered by the video retention days setting.
How long a sync waits after each new video it looks up. Spacing requests out stops big first syncs from getting your server rate-limited by YouTube, which also blocks playback. Videos already synced are reused from the cache and aren't looked up again.
Path to a Netscape-format cookies.txt exported from a browser signed in to YouTube. It makes "confirm you're not a bot" blocks much rarer and lets age-restricted videos play. The Jellyfin service must be able to read the file. Leave empty to not use cookies.

Enhanced Playback

Simple mode keeps setup light and works without ffmpeg. Enhanced mode uses ffmpeg to create a cleaner, more compatible playback stream and automatically falls back to Simple mode if it cannot start.
Path to the ffmpeg binary used by Enhanced mode. Use ffmpeg if it is available on PATH.
Choose how Enhanced mode encodes video. Start with Software if you are unsure, then switch to the hardware encoder that already works well on your server.
Unused Enhanced mode streams are stopped and cleaned up automatically after this many minutes.
Maximum number of Enhanced mode playbacks at the same time. Extra playbacks automatically fall back to Simple mode.

Subtitles

Saves YouTube subtitles next to each video, where Jellyfin shows them as external subtitle tracks. They are fetched along with each video's details, so this adds no extra YouTube requests.
Comma-separated language codes, for example en or en,de. A code also matches its regional variants, so en covers en-GB.
YouTube's automatic captions cover most videos but can contain mistakes.
